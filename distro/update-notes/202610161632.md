# Mentor update: a new icon for Mentor Settings

## What is new

Mentor Settings has its own icon now: the Mentor owl in a rounded square, the same as the new icon of the Mentor launcher on Windows.

## Why

New: /usr/share/icons/hicolor/256x256/apps/org.mentor.Settings.png and 512x512/…; org.mentor.Settings.desktop points to it (it used the assistant's icon). mentor-enable refreshes the icon cache. SETTINGS.md says how to make it again.

## Check at the end

- `mentor verify` says every file of Mentor's is as it was built.
- Mentor Settings shows the owl icon in the applications (after the next log-out at the latest).
