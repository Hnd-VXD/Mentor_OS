# Mentor update: copy text from the screen, reminders, websites as apps, and games on request

## What is new

- **Copy text from anything on the screen**: press Shift+Super+T and drag over the words, in a picture, a video or a program that does not let you select them. The text goes to the clipboard, ready to paste with Ctrl+V. If a word comes out wrong, ask Mentor to fix the text you copied.
- **Reminders**: say "remind me in 20 minutes to take the bread out", and a green card comes into the chat at that time. Reminders stay set when Mentor is restarted or shut down.
- **Websites as apps**: say "make WhatsApp an app", and it gets its own icon and opens in its own window, without the browser's bars.
- **Games**: ask Mentor for Steam (or Lutris, or Heroic) and it sets them up. Nothing for games is installed until you ask.

## Why

- Four features taken from Omarchy (github.com/omacom/omarchy, MIT), at the user's request.
- Copy text: `mentor capture-text` (key `mentor-text` in `/etc/dconf/db/local.d/00-mentor`), the tool `screen_text`, `read_text`/`capture_text`/`clipboard_set` in `mentor_tools.py`, and a new D-Bus method `SetClipboard` in the shell extension (it loads with the restart this update does). The language data `tesseract-data-eng` and `tesseract-data-ell` come as packages with this update (Mentor's package list); `tesseract` itself was there already. The last picture read is kept in `$XDG_RUNTIME_DIR/mentor-last-text.png` so that `screen_text` with `area` `last` can show it to you when the user says the copied text is wrong. DESKTOP.md, "Copy text from the screen".
- Reminders: the tools `reminder_set`, `reminder_list`, `reminder_cancel`; one systemd user timer per reminder in the user's own folders. TOOLS.md, "Reminders".
- Web apps: the tools `webapp_install`, `webapp_remove`, `webapp_list`; a launcher `~/.local/share/applications/mentor-webapp-NAME.desktop` that runs Chromium with `--app=`. TOOLS.md, "Web apps".
- Games: nothing installed. `/etc/mentor/GAMING.md` and `/etc/mentor/extras/gaming/setup-gaming.sh` (multilib, the 32-bit virtio graphics drivers, Steam, Lutris), run in the sandbox when the user asks.
- If Shift+Super+T does nothing after the update: the user's own list of custom keys overrides Mentor's; DESKTOP.md, "Copy text from the screen", "When it does not work", says how to add it.

## Check at the end

- `mentor verify` says every file of Mentor's is as it was built.
- `tesseract --list-langs` lists `eng` and `ell`.
- `gsettings get org.gnome.settings-daemon.plugins.media-keys custom-keybindings` ends with `.../custom-keybindings/mentor-text/`.
- `mentor reminders` answers "No reminders are set." (or lists the user's).
