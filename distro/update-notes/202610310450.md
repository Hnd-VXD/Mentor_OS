# Mentor update: a closer look that says what it is doing, and two false warnings gone

## What is new

- A closer look at a program now shows on its card what it is doing and for how long, like "Reading what its code can do: 0:23 (up to 5:00)".
- Every look now answers in seconds what the program asks of the system (network, starting programs, passwords). The deep read of its code (capa) runs only on small programs, since it cannot finish larger ones in the time.
- Two false warnings are gone: "A program read your passwords or keys" after an update of Mentor's own files, and "Something new starts by itself" naming systemd-journald-audit.socket.

## Why

capa took 90 seconds on 0.8 MB of machine code and over 5 minutes from about 2 MB, with no more speed from more processors, so a look seemed stuck and then gave nothing. The limit goes by machine code, not file size, since padding a file got past a file size limit. Writes to Mentor's own files reached the password check by mistake. mentor-enable masks that socket, and a masked unit starts nothing.

## Check at the end

- `mentor verify` says every file is as built.
- `auditctl -l` lists `mentor-own` with `perm=wa` and `success=1`.

If a card named above is still showing, it was false: tell the user it can be dismissed.
