# Mentor update: ask Mentor to check any program closely

## What is new

You can now ask Mentor whether a program is suspicious and have it look much more closely, even if Mentor had not flagged it. Mentor asks for your password first, and it changes nothing.

## Why

`security_investigate` answered only for programs on the guard's lists, so a user's own question got only a reading of the files. With `user_asked` and `explain` it now runs for any file through its own root action, `investigate` (`mentor_core.py`, `FACTS` in `mentor-rootd`, `--asked` in `mentor-investigate`): the root shell refuses commands that name Mentor's files. SECURITY.md, "A closer look at a flagged program".

## Check at the end

- `mentor verify` says every file is as built.
- `mentor call security_investigate '{"program": "/usr/bin/ls"}'` says "This looks only at programs the guard has flagged".
