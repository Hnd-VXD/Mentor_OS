# Mentor update: Mentor Settings opens again

## What is new

Mentor Settings did not open on a computer where a program had asked to go online. Now it opens.

## Why

`show_security` in `/usr/local/bin/mentor-settings` had `import mentor_guard` late in the function, which made the name local to all of it, so `mentor_guard.net_name` earlier in the function raised UnboundLocalError as soon as `net.json` listed a program. The process stayed running with no window, so every later try went to it and failed the same way. There since 2026-10-24 (5d7d9c5).

## Check at the end

- `mentor verify` says every file is as built.
- Mentor Settings opens, and its Security tab lists the programs that asked to go online.
