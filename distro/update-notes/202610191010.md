# Mentor update: the key box stays open

## What is new

- "Set a key for …" opens a box that now stays until you press Save or Cancel, also while you go to NVIDIA's page, Bitwarden or any other program to get the key.

## Why

- The user, 2026-10-19: the box closed as soon as they came back from another program. Coming back to the desktop re-checks the engine (`on_focus` in `mentor-chat`, for a sign-in done in a terminal), and a model that already has a key passed that check, so the chat took the box's place. `on_focus` now leaves a box for a new key (`change` in `connect_showing`) alone.
