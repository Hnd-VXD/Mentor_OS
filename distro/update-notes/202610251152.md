# Mentor update: long answers with links use the chat's whole width again

## What is new

A long answer that has links in it (with "Show more" under it) was squeezed into a column one word wide. It now uses the chat's width like every other answer.

## Why

An answer with links is an `AnswerView` (a text view, for the icons in front of the links), and a text view asks for almost no width of its own. A long answer sits in a box with "Show more", and that box was at the start, taking only the width its content asked for. In `/usr/local/bin/mentor-chat`, `add_text` now lets that box span the column when the answer has links; the view still narrows itself to its text (`fit`). ASSISTANT.md, "Links in answers, with icons", says so.
