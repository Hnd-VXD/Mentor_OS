# Mentor update: the desktop's zoom follows Windows better

## What is new

Mentor's desktop takes the zoom of your Windows screen, or the one you chose. Some window sizes cannot show every zoom, and then Mentor used to fall back to 100%, with tiny letters. Now it picks the nearest zoom the window can show (for example 133% when 150% does not fit).

## Why

Seen on the user's Mentor on 2026-11-14: a window of 2176x1360 takes only 100%, 133%, 200% and 267%; with a wish of 150% the rule "the largest quarter step not above the wish" gave 100%. The rule is now the nearest scale, a quarter step only when about as near (`nearest_scale` in `/usr/local/bin/mentor`, the same in the extension's `_applyScale`). DESKTOP.md, "Sharp text". The shell extension changed: it is used from the next login (the update restarts Mentor anyway).

## Check at the end

- `mentor verify` says every file is as built.
- `gdctl show` gives a scale near the one in `/run/mentor/host-scale` (or `~/.config/mentor/scale` when the user chose one).
