# Mentor update: clearer updates, and versions you can read

## What is new

When an update arrives, the card now has a "What's new?" button: Mentor tells you in a couple of simple sentences what it fixes and what that means for you. Mentor's version now reads like a date, for example 15.10.26.01, so it is easy to see how recent it is.

## Why

The image published on 15.10.26 (version 202610151906, shown as "15.10.26") came out just before two parts of the updater were finished:

- Updates can carry the maker's notes (this file): `notes`, `notes_size`, `notes_sha256` in update.json, kept after installing in /etc/mentor/update-notes/. The update card gets "What's new?"; after installing, "Mentor is up to date" gets "What's new?", or "Let Mentor finish" when the notes have steps.
- Version names: /etc/mentor/version-name (day.month.year and the build that day), shown on the cards, in `mentor update` and in Mentor Settings, Updates.

Changed: mentor_update.py, mentor (the command), mentor-chat (the card's buttons), mentor-settings (the Updates section), mentor_tools.py (notices with a button label), UPDATES.md, SETTINGS.md. Nothing else on the system changes. If the update card or Settings, Updates looks wrong since this update, those are the files to look at; `mentor verify` should say every file is as built.

## Check at the end

- `mentor update` names this version with four parts, like 15.10.26.01.
- `mentor verify` says every file of Mentor's is as it was built.
