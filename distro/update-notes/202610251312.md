# Mentor update: folders in answers can be clicked too

## What is new

When the assistant tells you where something is ("in your home folder"), the folder is now a link as well, with a folder icon: a click opens it in Files. Links to your files now always point to the right place.

## Why

`SYSTEM_PROMPT` in `/usr/local/bin/mentor-chat` gave only a file as the example of a link, so answers linked a file and left "your home folder" plain words; it now has an example with a folder named in the sentence. Its examples said `/home/USER`, and a model (Qwen on Groq) wrote that into its links, which point at nothing and showed as plain names: the chat now puts the user's real home folder into the examples. In `/usr/local/bin/mentor-agent`, "about 1 minutes" became "about 1 minute". ASSISTANT.md, "Links in answers, with icons", says so.

- `mentor verify` says every file is as built.
