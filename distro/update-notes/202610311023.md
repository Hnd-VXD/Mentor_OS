# Mentor update: a program in front asks over the full screen

## What is new

When the program you are using wants to go online and Mentor does not know it, the screen dims and the question shows on top of it, a full-screen game too. Block, Allow and Later start working after a 5-second count, so a key pressed in a game does not answer by accident.

## Why

The card for such a program is in the chat on the desktop, under the program, and GNOME shows no ordinary notification over a full-screen window: the program just stayed offline with no reason in sight. Programs in the background still get only their card. SECURITY.md, "The question over everything".

## Steps

Let the restart this update asks for happen: the shell loads the question at a new session.

## Check at the end

- `mentor verify` says every file is as built.
- `gdbus call --session -d org.gnome.Shell -o /org/mentor/Shell -m org.mentor.Shell.FocusPid` answers with a number.
