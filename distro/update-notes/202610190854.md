# Mentor update: programs start dark in a dark set

## What is new

- With dark window colors, programs such as Bitwarden, VS Code or Discord now open dark too, not light.

## Why

- The user, 2026-10-19: Bitwarden came up light in Warm charcoal. Electron programs learn GNOME's style from the desktop portal only a moment after they start, and most take light or dark at that first moment and never look again (tested with Electron 39: `nativeTheme.shouldUseDarkColors` false at `ready`, true a second later). `mentor_colors.prefer_dark()` now writes `gtk-application-prefer-dark-theme=1` (or `=0` in a light set) into `~/.config/gtk-3.0/settings.ini`, which Electron reads at once; `apply` calls it, and `buttons()` at every start of the chat. DESKTOP.md, "Window colors".

## Step by step

1. Nothing to do: the assistant writes the line when it starts again after the update. A program that is open shows it when it is opened again (Bitwarden: quit it from its menu, not only the window).

## Check at the end

- `mentor verify` says every file of Mentor's is as it was built.
- In a dark set, `grep prefer-dark ~/.config/gtk-3.0/settings.ini` says `=1`; in a light one `=0`.
