# Mentor update: Mentor Settings in the desktop menu

## What is new

Right-click on the desktop now offers Mentor Settings next to Settings, and the extra Display Settings entry is gone (it is inside Settings). Mentor keeps this menu exactly like this from now on, also after updates of the desktop.

## Why

- mentor-chat: the menu's last section is Change Background…, Mentor Settings…, Settings (Display Settings removed).
- AGENT.md: the menu's layout is the user's choice and a fixed rule: never changed unless the user asks, checked after a GNOME upgrade and put back if it differs. DESKTOP.md: that check is part of step 4 of a new GNOME version.

Changed: mentor-chat, AGENT.md, DESKTOP.md, ASSISTANT.md, SETTINGS.md.

## Check at the end

- `mentor verify` says every file of Mentor's is as it was built.
- Right-clicking the desktop shows Hide chat, New conversation | Report a problem… | Change Background…, Mentor Settings…, Settings.
