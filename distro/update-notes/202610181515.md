# Mentor update: Alt+Shift switches the keyboard language

## What is new

- Alt+Shift switches between your keyboard languages (for example English and Greek), as on Windows. Super+Space still works too.
- Shortcuts with Alt+Shift in them (Alt+Shift+Tab, Alt+Shift+F in some programs) keep working and do not change the language.

## Why

- GNOME switches layouts only with Super+Space; the user, used to Windows, pressed Alt+Shift and nothing happened (2026-10-18). GNOME's own Alt+Shift option switches as the keys go down, so Alt+Shift+Tab and Alt+Shift+F changed the language too (tested). Instead `mentor-emergency-key`, which already reads the keyboards below GNOME, switches when Alt+Shift is let go with no other key, through the extension's new D-Bus method `NextInputSource` (GNOME's own switcher). DESKTOP.md, "Keyboard layouts". The same on a Mentor started on its own PC.

## Check at the end

- `mentor verify` says every file of Mentor's is as it was built.
- `systemctl is-active mentor-emergency-key` says `active`.
