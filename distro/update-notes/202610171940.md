# Mentor update: no more jump in size when the window is maximized or made full screen

## What is new

- When you maximize Mentor's window or make it full screen, everything used to show small for about a second and then jump to your usual size. Now it changes almost at once.

## Why

- After the window's size changes, GNOME shows the new size at 100% until the scale is set again. The shell extension used to start `mentor scale` for that, 0.6 s after the change, which took about 1.2 s in all. It now sets the scale itself (`_applyScale` in extension.js, through mutter's `org.gnome.Mutter.DisplayConfig`, with the same rules as `mentor scale`) 0.1 s after the change: about 0.2 s. If that fails, the log says `mentor: scaling directly failed (…)` and `mentor scale --keep` does it as before. DESKTOP.md, "Sharp text".

## Check at the end

- `mentor verify` says every file of Mentor's is as it was built.
- `journalctl --user -b -o cat | grep "mentor: scaling"` prints nothing.
