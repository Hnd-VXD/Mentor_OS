# Mentor update: more zoom levels

## What is new

You can now choose how large everything is drawn, from 100% to 300% in steps of 25%: Mentor Settings, tab Themes, Zoom. Some window sizes cannot show every zoom exactly; then the screen takes the nearest one it can, and the letters are made larger or smaller to match the zoom you chose.

## Why

The user's wish, 2026-11-14: GNOME's own Settings offers only the scales the window's exact size takes (100%, 150% and 300% for a maximized window of 2880x1659). Now: Mentor Settings' Zoom row (`~/.config/mentor/scale`), the nearest real scale (`nearest_scale`), and `text-scaling-factor` for the rest (`text_fill` in `mentor`, `_fillWithText` in the extension), left alone when the user set the letters' size themselves. A scale Mentor sets is no longer taken for the user's choice (`_ownScaleChange`). DESKTOP.md, "Sharp text"; SETTINGS.md. The shell extension changed: it is used from the next start.

## Check at the end

- `mentor verify` says every file is as built.
- `gsettings get org.gnome.desktop.interface text-scaling-factor` and `cat ~/.config/mentor/text-scale` give the same number (or the file is missing and the setting is 1.0).
