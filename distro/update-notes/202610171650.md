# Mentor update: the simpler owl on the setup screens

## What is new

- The screens where you set Mentor up (the welcome, "Connect the agent" and the keyring card) now show the simpler owl, the same one as Mentor Settings' icon. It is clearer at that size. Nothing else changes; the start-up screen stays as it was.

## Why

- The user chose the simpler owl for the big cards in the middle of the desktop. `mentor-chat` shows them with `CARD_ICON = "org.mentor.Settings"` (the icon that already comes with Mentor Settings) instead of the assistant's own round emblem `org.mentor.Chat`, which stays the assistant's icon everywhere else. ASSISTANT.md says so. The boot splash is not touched.

## Check at the end

- `mentor verify` says every file of Mentor's is as it was built.
