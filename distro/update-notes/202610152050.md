# Mentor update: Mentor Settings uses the whole window

## What is new

Mentor Settings now spreads across the window like the Recipes app, instead of a narrow column in the middle, on both its tabs.

## Why

mentor-settings used Adw.PreferencesPage, which stops at about 600 pixels. Both tabs now use WidePage (the same as mentor-recipes): an Adw.Clamp up to 1100 pixels.

Changed: mentor-settings.

## Check at the end

- `mentor update` names this version 15.10.26.05.
- `mentor verify` says every file of Mentor's is as it was built.
