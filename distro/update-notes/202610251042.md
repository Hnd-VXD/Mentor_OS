# Mentor update: Groq's fast free models, and a web search that finds real pages

## What is new

The assistant can now run on Groq's free models, which answer in a second or two: choose "Groq (free, fast)" in the model menu beside the text box and paste a free key from Groq's page. Groq's free plan takes only so much a minute, so on a long task the assistant may pause for a few seconds between steps and says so. The assistant's web search now finds real pages: before, it often came back with unrelated news and shops.

## Why

- **Groq in light mode** (`/usr/local/bin/mentor-agent`, `LIGHT`; ENGINES.md "Groq, in light mode"): Groq's free plan takes at most 8,000 tokens a minute (Qwen 7,000), and a whole Mentor request is about 16,500. In light mode the model gets the system prompt, a short note, twelve main tools and `tool_find` for the others, reads the instructions with `docs_find`, and the conversation is shortened to fit; it waits for the limit and says so under the spinner, stops a turn at 24 steps, and answers in plain words when the provider refuses. Every mentor-agent model is now told its own name, and requests carry a User-Agent (Groq's front refused Python's own). In `mentor-chat`: three Groq models (GPT OSS 120B, Qwen 3.8 27B, GPT OSS 20B), the key card (Groq keys start with `gsk_`; copied on Groq's page, the key comes back into the card by itself). `mentor repair` can use a Groq key (`~/.config/mentor/keys/groq`); shared recipes refuse Groq keys.
- **web_search** (`/usr/local/lib/mentor/mentor_tools.py`; TOOLS.md "The web"): DuckDuckGo shows a robot check after a few quick searches, and the fallback, Bing, answered English queries with unrelated local news, which the assistant took for results. Now Brave and DuckDuckGo take turns, one that refuses rests ten minutes, searches are a few seconds apart, the same search is answered from a cache for 15 minutes (`~/.cache/mentor/web-search.json`), results that share no word with the query are dropped, and when both engines refuse it asks the ArchWiki, GitHub and Wikipedia and says so.
- If the user says Groq does not answer: ENGINES.md, "Groq, in light mode". If searches come back empty or "refused for now": TOOLS.md, "The web" (`cat ~/.cache/mentor/web-search.json` shows which engine rests until when).

## Check at the end

- `web_search` for a program's name gives pages about that program.
