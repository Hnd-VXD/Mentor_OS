# Mentor update: clearer checks of recipes

## What is new

- When Mentor checks a recipe, its list of the commands the recipe would run is now complete and only holds commands, not the lines of files the recipe writes.

## Why

- The rules' report (`mentor_recipes.inspect`) took every line of every code block as a command. A recipe that writes a long file (a ```javascript extension, a ```json file) filled the list's 80 places with the file's lines, and its real commands after it (enabling, removing) were cut off the list the user reads. Commands now come only from shell blocks (```bash, ```sh, or no language) and inline commands; risks and paths are still read from everything. RECIPES.md, "How to tell that it works".
- recipe_hub_look takes `query` as well as `search` (a search under the other name used to find nothing, silently).
- mentor-sentinel's probe of the desktop shows its name in `ps` instead of an anonymous script.

## Check at the end

- `mentor verify` says every file of Mentor's is as it was built.
