# Mentor update: the chat's cards as frosted glass

## What is new

The assistant's cards on the desktop now look like frosted glass: the wallpaper behind them shows through softly blurred, and the text stays easy to read. The box over a program (Super+Z, Alt+Space) stays solid, as before. This needs a graphics card; without one, Mentor keeps the old look so it stays quick.

## Why

GNOME 51 can blur what is behind part of a window (mutter, `ext-background-effect-v1`), and GTK 4.24 asks for it wherever the CSS has a `backdrop-filter`. `mentor-chat` adds `GLASS_CSS` at startup unless `drawn_without_graphics_card()` is true (a virtio-gpu without 3D, or no `/dev/dri/renderD*`, the same test as the animations). Without a graphics card the blur made the shell use about seven times its processor time. If the user finds the cards too see-through or the text hard to read, DESKTOP.md, "Frosted glass", says what to change. Only `/usr/local/bin/mentor-chat` and `/etc/mentor/DESKTOP.md` changed.

## Check at the end

- `mentor verify` says every file is as built.
- `pgrep -af bin/mentor-chat` shows the assistant running.
- With a graphics card, a busy wallpaper behind a card looks soft; without one, it looks sharp, as before.
