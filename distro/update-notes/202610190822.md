# Mentor update: skip an article, or a whole site

## What is new

- The cards behind the bell say plainly what each button does. On news: **Skip article** brings the next news into the same place, and **Don't show news from LWN** (the site's own name) stops that one site while the others go on. GitHub projects, new apps and recipes have the same two buttons ("Don't show news from GitHub", "Skip article", which brings the next few).
- **Not now** (on the cards about the disk, updates and something that stopped) waits one day instead of three.
- Mentor Settings, Suggestions, lists the sites turned away and the cards skipped, each with **Bring back**.

## Why

- The user, 2026-10-19: "Don't suggest this again" on one article turned away the news of all five sites, while it read like "this article". `mentor-chat`: `skip()`, `news_source()`, `ARTICLE_KINDS`, `SEE_ONCE_KINDS`, `KIND_SOURCES`; a card brought by Skip keeps `"replaces"` so it shows in the place of the one skipped. `~/.config/mentor/advice.json` gains `hidden` (skipped cards, id -> title) and `sources_off` (sites, "LWN"). `mentor-advisor` writes each article's `source`. `suggestions_status` and `suggestions_restore` know both. SUGGESTIONS.md, SETTINGS.md.

## Step by step

1. Nothing to do: the assistant starts again with the new code when the update is installed. Cards already behind the bell get the new buttons at once (their site is read from the start of the title until the advisor's next run adds it).
