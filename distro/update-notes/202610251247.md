# Mentor update: the assistant's notes on a rare crash of the chat

## What is new

Nothing changes in how Mentor looks or works. The assistant's own notes now describe a rare crash of the chat caused by GTK, the toolkit it is drawn with, together with the frosted glass, so it can tell you plainly what happened if it ever closes by itself.

## Why

On 2026-10-25 the chat crashed once (SIGSEGV in `libgtk-4.so.1`, `region_create_from_bitmap` ← `compute_background_blur`): GTK 4.24's background blur, which runs only with `backdrop-filter` (the frosted glass), reads a cairo picture that was never made when a clip has a size cairo refuses. It is a GTK bug, reported to GTK; the user chose to keep the glass. The extension starts the chat again after 3 s and the conversations are kept. Only `/etc/mentor/DESKTOP.md` ("Frosted glass": how to recognize it, what to say, when to leave the glass out) and `/etc/mentor/FREEZES.md` ("When a program crashes" points there) changed.
