# Mentor update: small fixes found by testing

## What is new

- After Mentor starts, Ctrl and the mouse wheel make the chat's text larger or smaller right away; before, you had to click into the chat first.
- A card that arrives while the Super+Z text box is open over a program no longer shows half-hidden under it.
- Copying text from the screen reads English and Greek more reliably, and says plainly when a file is not a picture.

## Why

- Zoom: on Wayland an app sees Ctrl only while it has the keyboard, and after a start nothing had it. The shell extension now gives the assistant the keyboard whenever no other window has it (`_focusWhenAlone`). ASSISTANT.md, "Larger or smaller text".
- Ask bar: lifting the text box out emptied its place on the desktop, and the conversation behind ran under the floating box; its place now keeps its height (`ask` / `close_ask` in mentor-chat).
- Copy text: a languages file naming a language that is not installed fell back to every installed one, Afrikaans too, which misreads; it now falls back to English and Greek. A file that is not a picture was handed to tesseract, which took it for a list of pictures; it is now refused in one sentence.

## Check at the end

- `mentor verify` says every file of Mentor's is as it was built.
- `mentor doctor` says everything of Mentor's desktop is in place.
