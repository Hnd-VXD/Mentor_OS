# Mentor update: an Updates tab with every update

## What is new

Mentor Settings now has its own Updates tab. It shows which Mentor you have, lets you look for an update, and lists every update this Mentor had. Next to each one, "Ask Mentor" has the assistant go over it with you and check that it works.

## Why

- Mentor Settings is two tabs now (Adw.ViewStack): Settings, and Updates (`mentor settings updates` opens it). Updates: the version, a waiting update (What's new?, Update), Look, and "Every update" from `history` in /var/lib/mentor/updates/state.json, each with Ask Mentor (UPDATES.md says what to do with that request).
- mentor_update.py keeps that history (installed, or undone when the start after it failed). An update installed before this one shows from the older `installed` record, without its summary.
- The look after a start comes 1 minute after it instead of 3 (mentor-update-check.timer), and Settings no longer says "being tried" once the start with the update has worked.
- The log now counts only files really removed and packages really installed (15.10.26.01 listed packages that were already there; nothing was installed).

Changed: mentor-settings, mentor_update.py, mentor (the command), mentor-update-check.timer, UPDATES.md, SETTINGS.md.

## Check at the end

- `mentor update` names this version 15.10.26.02.
- `mentor verify` says every file of Mentor's is as it was built.
- Mentor Settings has the tabs Settings and Updates.
