# Mentor update: safer file tools

## What is new

Mentor's assistant handles files more carefully. When it changes a file in your home folder twice in quick succession, both earlier versions are kept, so undo can go back step by step, and the file is never left half written. It no longer gets stuck trying to read a huge file or a special system file. A full system upgrade no longer claims a restore point that does not exist.

## Why

A code review on 2026-11-14 found these; each was tried on a test Mentor:

- `file_write` in the home: earlier versions in folders of their own (date, time, nanoseconds), the new version written whole (`mentor_tools.py`). TOOLS.md.
- `file_read` and `file_search`: pipes, devices and files over 64 MB (`READ_BIG`) are refused with words instead of hanging or filling the memory. TOOLS.md.
- `system_upgrade`: the journal names the launcher's restore point as the way back only when one was made (`_noted["restore_point"]`).
- `mentor-chat --file PATH`: a relative path is taken from the caller's folder; pasted pictures get names of their own. ASSISTANT.md.

## Check at the end

- `mentor verify` says every file is as built.
