# Mentor update: mouse-look in 3D games, and Delete in the Recipes app

## What is new

- In 3D games the view now turns with the mouse. While a game is in front, Mentor switches to a "game mouse" by itself. Click once inside the game, and the view follows the mouse. Leave the game, and the normal pointer is back. Ctrl+Alt+G gives the pointer back to Windows at any time (in a normal window).
- This needs the newest Mentor program on Windows. If yours is older, Mentor tells you how to get it: run MentorSetup.exe again and choose the same folder. Nothing inside Mentor is lost.
- In the Recipes app, an opened recipe of yours (or a downloaded one not used yet) has a red Delete button. It asks first, and then erases the recipe from this computer.

## Why

- The game mouse: Mentor's window gave the system only a tablet, which says where the pointer is but not how far it moved. Games that hold the pointer turn the view by how far it moved, so menus worked and the view did not. Mentor.exe now also gives a Virtio mouse and switches to it on request. The shell extension's new part `game mouse` asks for it while an app with `Categories=Game` (or one listed in `~/.config/mentor/game-mouse.json`) is in front. Changed: `extension.js`, `mentor_tools.py` (tool `game_mouse`), `/usr/local/bin/mentor` (`mentor game-mouse`), mentor-chat's instructions, AGENT.md, TOOLS.md, DESKTOP.md ("The game mouse": what to tell the user and what to do when it does not work), REBUILD.md.
- Delete in Recipes: the user asked for a way to get rid of a recipe. Changed: `/usr/local/bin/mentor-recipes` (`delete_button`, `delete`) and RECIPES.md ("Deleting a recipe").

## Steps

1. **See whether the program on Windows can give the game mouse.**
   - Look first: run_command `grep -c 'QEMU Virtio Mouse' /proc/bus/input/devices`.
   - If it prints 1: nothing to do here.
   - If it prints 0: the user's Mentor.exe is from before the game mouse. Change nothing. At the end, tell the user in one sentence: "For mouse-look in 3D games, close Mentor, run MentorSetup.exe again and choose the same folder: it only fetches the new Mentor program, and nothing inside Mentor is lost."

## Check at the end

- `mentor verify` says every file of Mentor's is as it was built.
- `mentor doctor` lists no broken part. The shell's `Status` has `"game mouse": "ok"`.
- `mentor game-mouse` prints `Setting: auto`.
