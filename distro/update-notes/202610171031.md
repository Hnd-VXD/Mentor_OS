# Mentor update: make the chat's text larger or smaller

## What is new

- Hold Ctrl and turn the mouse wheel over the chat to make its text larger or smaller, from 70% to 200%. Ctrl and + or − do the same, and Ctrl and 0 sets it back to normal.
- The cards get wider as the text grows, so each line still holds about as many words.
- A small label at the top right shows the size for a moment. Mentor remembers the size you choose.

## Why

- mentor-chat: a user asked for this, and their own Mentor made it as a recipe. The recipes site refuses recipes that change Mentor's own files, so the feature is now part of Mentor itself. The conversation's scroller has the CSS class `chat-zoom`. A second CSS provider sets its font-size in percent. Each conversation's column (`Adw.Clamp`) is set to 720 pixels × the zoom. The size is kept in `~/.config/mentor/chat.json` as `"zoom"`. The functions are `on_zoom_scroll`, `on_zoom_key`, `set_zoom` and `zoom_css`. ASSISTANT.md ("Larger or smaller text") has the details.
- The text box at the bottom and the box over a program (Super+Z) keep their size.

Changed: mentor-chat, ASSISTANT.md.

## Steps

1. **Take away an earlier zoom made by the assistant itself, if there is one.**
   - Look first: read `~/.local/share/mentor/notes.md` and the user's recipes folder (`~/Documents/Mentor recipes/`) for a zoom of Mentor Chat's text made on this computer (for example "zoom-text-and-widen-cards-in-mentor-chat.md").
   - If there is one: this update has replaced the file it changed (`/usr/local/bin/mentor-chat`), so do not apply it again. Add a line to notes.md saying that the zoom is now part of Mentor (Ctrl + mouse wheel, Ctrl + + − 0). Do not delete the recipe file. Tell the user that they no longer need it and can delete it if they want to.
   - If there is none: nothing to do.

## Check at the end

- `mentor verify` says that every file of Mentor's is as it was built.
- Ctrl and the mouse wheel over the chat change the text size, and a label with the size shows at the top right.
