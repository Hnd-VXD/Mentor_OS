# Mentor update: one volume for Windows and Mentor, now also with the laptop's volume keys

## What is new

- Your laptop's volume keys, Windows' volume and Mentor's volume are one and the same, and a key press now moves the volume one step, not two. Mute is shared too.
- This needs the newest Mentor program on Windows, which updates itself. With an older one, Mentor's volume works as before.

## Why

- The one volume (update 17.10.26.09; WINDOWS.md, section 5, "One volume"), plus: the laptop's volume keys reached both Windows and this system, so one press moved the volume twice. While the volumes are joined, `mentor-volume` empties GNOME's own volume keys (`org.gnome.settings-daemon.plugins.media-keys` `volume-*-static`), keeps the user's values in `~/.local/state/mentor/volume-keys.json`, and puts them back when Mentor.exe goes away; GNOME's media-keys service is started again each time, since it reads them only at its start.
- If the volume keys inside Mentor do nothing after Mentor.exe is gone: WINDOWS.md, section 5, "One volume", point 4.

## Check at the end

- `mentor verify` says every file of Mentor's is as it was built.
- With the newest Mentor.exe: `pactl get-default-sink` says `mentor_speakers`, and its volume is Windows' volume.
