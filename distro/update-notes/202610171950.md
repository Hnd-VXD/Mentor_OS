# Mentor update: working together with the new Mentor program on Windows

## What is new

- With the new Mentor program on Windows, Mentor now follows your Windows time zone by itself.
- You can approve Mentor's password questions with Windows Hello (your face, finger or PIN), if you switch it on in the Mentor window under "Sound, USB and sign-in". Your password always keeps working too.
- With an older Mentor program on Windows nothing changes.

## Why

- The guest half of the launcher features: `mentor-host-link` (started by `/etc/udev/rules.d/70-mentor-host.rules` when Mentor.exe's port `org.mentor.host` exists; it sets the time zone Mentor.exe reports), `mentor-hello` (asked first by `/etc/pam.d/polkit-1` and `/etc/pam.d/sudo`; without the port or with Hello off it ends at once and the password is asked as always), a hint in `mentor-rootd`. All of it in `/etc/mentor/WINDOWS.md`. AGENT.md, BOOT.md and REBUILD.md point to it.
- If a password prompt behaves oddly since this update: WINDOWS.md, section 8, "When it does not work".

## Check at the end

- `mentor verify` says every file of Mentor's is as it was built.
- `sudo -k; sudo true` asks for the password as before (or, with Windows Hello on, shows the Windows prompt).
- With the new Mentor.exe: `systemctl is-active mentor-host-link` says `active`.
