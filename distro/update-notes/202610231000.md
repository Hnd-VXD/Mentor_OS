# Mentor update: a clearer repair screen, and an easier Claude sign-in

## What is new

- Repair mode's text screen has letters sized for your screen, like the rest of Windows, so the place to type (`you>`) is always in view. Before, the letters were twice the size and the last line could be cut off.
- With the newest Mentor.exe, Repair shows the same loading window as a normal start ("Starting Mentor in repair mode…") and switches to the repair screen when it is ready.
- When you sign in to Claude, the window first tells you that your browser opens by itself, that the long link below is not needed, and how to paste a code if the browser shows one.

## Why

- Repair letters: `/usr/local/lib/mentor/mentor-repair-console` picks the console font from the host's screen scaling (fw_cfg `opt/mentor/scale`): the usual 8x16 up to 1.2, `LatGrkCyr-12x22` below 2, the usual doubled (`setfont -d`) from 2. It used to double it always, and the launcher showed the small picture stretched over its window, so the bottom line (the prompt) was cut and the pointer could not leave the window but on the left. The newest Mentor.exe draws the repair screen in its window's real pixels (`video=Virtual-1:WxH` on the kernel command line). `/etc/profile.d/mentor-repair.sh` no longer sets a font itself. REPAIR.md, "How the console looks" and "The console".
- Repair loading window: `mentor-repair-console` tells the launcher `{"boot": "repair"}` on `org.mentor.control` when the screen is up (in the background, best effort; on a real machine there is no such port).
- Claude sign-in: `/usr/local/lib/mentor/mentor-engine claude` prints the hint before `claude auth login`. Opening Claude Code's printed link as well as the browser it opened starts a second sign-in, which can make the first one fail with "Request failed with status code 400".
- If the repair letters look wrong: `cat /sys/firmware/qemu_fw_cfg/by_name/opt/mentor/scale/raw` (the scaling the launcher passed) and `cat /sys/class/graphics/fb0/virtual_size` (the screen's size).

## Check at the end

- `mentor verify` says every file of Mentor's is as it was built.
