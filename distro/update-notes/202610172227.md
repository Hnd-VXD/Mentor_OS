# Mentor update: changing your password the easy way

## What is new

- "Change my password" in Mentor Settings now opens a simple window where you type your old password and a new one twice, with dots you can show, instead of a black text window.

## Why

- It used to open a Console on `passwd`: a red title bar (the Console marks programs with root rights) and a "Current password:" prompt that shows nothing as one types. Mentor Settings' Change button now opens GNOME Settings on System, Users (`gnome-control-center system users`, through /usr/local/bin so it is drawn without OpenGL), where Password opens GNOME's dialog. The card "Your password is still the one every Mentor starts with" asks you to open the same page (app_open gnome-control-center, arguments `system users`). SETTINGS.md and SECURITY.md say so. Tested: the new password works for sudo, the old one no longer does, and the keyring still opens by itself after a restart.

## Check at the end

- `mentor verify` says every file of Mentor's is as it was built.
