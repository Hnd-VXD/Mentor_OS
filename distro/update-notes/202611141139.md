# Mentor update: stronger protections, as you chose

## What is new

The password window now always says what will really happen (the programs, the file or the command) under Mentor's short explanation, so a harmful program cannot hide what it asks for behind nice words. The setting "Show the exact command when my password is asked" is gone: it is always shown now. Mentor no longer trusts notes in your home folder to decide what it installed itself. The emergency console (Ctrl+Alt+Backspace) asks for your password when your computer does not log you in by itself. And Mentor now also watches its own protected files that only the system can read.

## Why

The user's choices after a code review on 2026-11-14; each was tried on a test Mentor:

- Password dialog (`mentor-rootd`, `said`): the line with the real action is always added; `exact` is no longer read, and its switch left Mentor Settings. SECURITY.md, "What the password dialog says"; TOOLS.md.
- Whose doing a program is (`mentor_guard._mentor_journal_text`, used by the guard and `mentor-netguard`): from root's audit log and applied changes, not the home journal. For passwords, keys and browser data nothing in a home counts as known (`trusted(..., strict=True)`). Something the assistant made in the home without root now gets a card the first time it goes online: that is expected. SECURITY.md, "Whose doing is it".
- Emergency console (`mentor-emergency-console`, `mentor-repair-console`): passwordless only with automatic login on. FREEZES.md.
- Mentor's root-only files (the polkit rules) are checked by the guard (`root_only_findings`): a changed one gives "One of Mentor's protected files was changed".

## Check at the end

- `mentor verify` says every file is as built.
- `systemctl is-active mentor-guard.timer mentor-netguard` says active.
